# بازرس پراکسی

**فارسی** | [English](README.en.md)

یک رابط وب سبک و سریع برای مشاهده، جستجو، فیلتر و مرتب‌سازی پراکسی‌های به‌روز از [monosans/proxy-list](https://github.com/monosans/proxy-list).

بدون هیچ وابستگی، بدون مرحلهٔ ساخت — فقط HTML، CSS و جاوااسکریپت خام.

## امکانات

- دریافت زندهٔ `proxies.json` از مخزن اصلی (با نسخهٔ آفلاین پشتیبان)
- جستجو در میزبان، پورت، کشور، شهر، شبکه (ASN) و IP خروجی
- فیلتر بر اساس پروتکل (http / socks4 / socks5)، کشور و حداکثر تأخیر
- مرتب‌سازی با کلیک روی هر ستون
- کپی تکی یا کپی گروهی همهٔ نتایج فیلترشده
- خروجی CSV از نتایج فیلترشده
- حالت تاریک با اولویت به تنظیمات سیستم (و ذخیرهٔ انتخاب کاربر)
- رابط واکنش‌گرا برای موبایل و دسکتاپ

## اجرا به‌صورت محلی

```bash
python -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

## انتشار روی GitHub Pages

1. یک مخزن عمومی در گیت‌هاب بسازید و این فایل‌ها را در شاخهٔ `main` پوش کنید
2. در **Settings → Pages** گزینهٔ **Deploy from a branch** را انتخاب کنید
3. شاخه `main` و پوشهٔ `/ (root)` را انتخاب و ذخیره کنید

پس از چند ثانیه، سایت روی `https://<username>.github.io/<repo>/` در دسترس خواهد بود.

## دربارهٔ داده‌ها

داده‌ها از [`monosans/proxy-list`](https://github.com/monosans/proxy-list) می‌آیند و مستقیم از همان مخزن خوانده می‌شوند. اعداد «تأخیر» (Latency) همان فیلد `timeout` در فایل JSON هستند که توسط پروژهٔ منبع اندازه‌گیری شده‌اند — مرورگر شما هیچ تستی روی پراکسی‌ها انجام نمی‌دهد.
